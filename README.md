# سامانه مدیریت یادگیری و آزمون الکترونیکی سازمانی (Enterprise LMS)

این مخزن شامل سورس‌کد کامل، پکیج استقرار آماده هاست و اسکریپت‌های نصب خودکار **سامانه مدیریت یادگیری و آزمون الکترونیکی سازمانی** می‌باشد.

---

## 🚀 ویژگی‌های کلیدی سامانه

1. **طراحی بومی و راست‌چین (RTL) سازمانی**: منطبق با استانداردهای پورتال‌های آموزش سازمانی صنایع بزرگ کشور.
2. **تقویم داخلی هجری شمسی**: انتخاب تعاملی تاریخ شمسی به همراه قابلیت تایپ و درج دستی، با پشتیبانی کامل از سال‌های کبیسه و محاسبات دقیق جلالی بدون وابستگی خارجی.
3. **ماتریس جامع دسترسی‌ها (RBAC)**: تعریف سطوح دسترسی دقیق برای مدیر ارشد (Super Admin)، مدیر آموزش (Training Manager)، مدرس (Instructor) و فراگیر (Learner) با کنترل خواندن، نوشتن و حذف در تمامی بخش‌ها.
4. **ماژول مدیریت کلاس‌ها و دوره‌ها**: ساختار درختی محتوا، فصول، جلسات آنلاین، آزمون‌ها و دوره‌های پیش‌نیاز.
5. **بانک سوالات و آزمون‌ساز چندگزینه‌ای و تشریحی**: با تایمر، تصحیح خودکار، کارنامه و صدور گواهینامه.
6. **مدیریت منابع و استانداردهای آموزشی**: بارگذاری ویدئو، اسلاید، پادکست، جزوات و بسته‌های تعاملی چندرسانه‌ای.
7. **پایگاه‌داده رابطه‌ای SQL**: مجهز به اسکریپت ساخت جداول استاندارد MySQL و کنسول داخلی SQL.
8. **پکیج بدون محدودیت برای هاست**: امکان اضافه کردن هرگونه فایل، ویدئو و پوشه به صورت مستقیم در cPanel بدون نیاز به بیلد یا ابزار جانبی.

---

## 📦 محتویات بسته استقرار هاست (`host_package/` و `lms-host-package.zip`)

محتوای پوشه `host_package` یا فایل فشرده `lms-host-package.zip` به گونه‌ای طراحی شده که مستقیماً در ریشه هاست (`public_html`) کپی می‌شود و شامل فایل‌های زیر است:

- `index.html`: هسته اجرایی بهینه شده سامانه با بارگذاری پرسرعت.
- `config.js`: فایل تنظیمات مستقیم هاست. **بدون نیاز به کامپایل مجدد، با ویرایش این فایل در File Manager هاست می‌توانید عناوین، آدرس‌ها و مسیرها را تغییر دهید.**
- `install.php`: ویزارد خودکار و ۴ مرحله‌ای تحت‌وب جهت نصب پایگاه‌داده MySQL، ساخت حساب مدیر ارشد و ایجاد پوشه‌ها.
- `api.php`: وب‌سرویس RESTful جهت مدیریت داده‌ها، ثبت کاربران و بارگذاری فایل‌ها روی سرور.
- `database.sql`: اسکریپت استاندارد ساخت ۱۴ جدول رابطه‌ای سامانه به همراه ایندکس‌ها و داده‌های اولیه.
- `.htaccess`: کانفیگ بهینه‌شده آپاچی برای ریدایرکت، استریم روان ویدئوها (Range Requests)، پشتیبانی از فایل‌های حجیم و امنیت دسترسی به پوشه‌ها.
- پوشه `uploads/`: شامل زیرپوشه‌های تفکیک‌شده:
  - `uploads/videos/`: ذخیره‌سازی فیلم‌ها و ویدئوهای دوره‌ها (MP4, WebM)
  - `uploads/documents/`: جزوات و اسناد آموزشی (PDF, Word, Excel)
  - `uploads/scorm/`: بسته‌های چندرسانه‌ای و تعاملی SCORM
  - `uploads/images/`: تصاویر و پوسترهای دوره‌ها
  - `uploads/audio/`: فایل‌های صوتی و پادکست‌های آموزشی

---

## 🛠️ راهنمای سریع نصب روی هاست (cPanel / DirectAdmin)

1. محتویات پوشه `host_package` (یا فایل `lms-host-package.zip`) را در پوشه `public_html` هاست آپلود و Extract کنید.
2. در cPanel وارد بخش **MySQL Databases** شده و یک دیتابیس و نام‌کاربری جدید بسازید و تمام دسترسی‌ها (ALL PRIVILEGES) را به کاربر بدهید.
3. در مرورگر خود آدرس نصب را باز کنید:  
   `https://yourdomain.com/install.php`
4. اطلاعات دیتابیس ساخته شده و مشخصات مدیر ارشد را وارد نمایید و دکمه «نصب و راه‌اندازی» را بزنید.
5. پس از پایان نصب، سامانه آماده استفاده است و تمامی پوشه‌های آپلود با دسترسی مناسب ایجاد می‌گردند.

---

## 📂 افزودن فایل و فولدر به هاست بدون هیچ‌گونه محدودیت

این سامانه معماری کاملاً آزادی دارد:
- هر زمان بخواهید ویدئو، فایل PDF یا دوره جدیدی اضافه کنید، می‌توانید مستقیم از **cPanel File Manager** یا پروتکل **FTP** فایل‌ها را در پوشه `uploads/` یا هر پوشه دلخواه جدیدی قرار دهید.
- هیچ محدودیتی در ساختار فولدرها روی هاست وجود ندارد و سامانه به صورت زنده فایل‌ها را از سرور فراخوانی می‌کند.
- جهت تغییر تنظیمات، فایل `config.js` را باز کرده و مسیرها را مطابق میل خود شخصی‌سازی کنید.

## 💻 توسعه و بیلد مجدد (در صورت نیاز به توسعه سورس‌کد)

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه محلی
npm run dev

# تولید بیلد جدید برای هاست
npm run build
```
